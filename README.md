## CONTROLS

- `F10` = Open / close
- `Up / Down` = Navigate
- `Enter` = Toggle or run selected action
- `Esc` = Close overlay

## INSTALL

1. Fully close Dishonored.
2. Extract into the game root.
3. Overwrite `Binaries\Win32\Mods\ModLoader.dll`.
4. Launch with `Luvvy-Launch.bat`.
5. Load gameplay and press `F10`.
